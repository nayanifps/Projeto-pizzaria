# 🍕 Forno de Ouro — Pizzaria Artesanal

## 📌 Sobre o projeto

O **Forno de Ouro** é um site desenvolvido para uma pizzaria artesanal, com o objetivo de apresentar os produtos, divulgar o estabelecimento e facilitar os pedidos dos clientes.

O site possui um visual moderno, organizado e responsivo, permitindo que os usuários naveguem pelo cardápio e realizem seus pedidos de forma simples.

## 🚀 Funcionalidades

- Página inicial com apresentação da pizzaria.
- Cardápio com diferentes opções de pizzas.
- Seção de bebidas e sobremesas.
- Carrinho de compras para adicionar e remover produtos.
- Controle de quantidade dos itens.
- Cálculo automático do valor total.
- Formulário para preenchimento dos dados do cliente.
- Seleção da forma de pagamento.
- Finalização do pedido pelo WhatsApp.
- Seção sobre a história da pizzaria.
- Área de depoimentos de clientes.
- Informações de contato e funcionamento.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e organização visual do site.
- **JavaScript:** funcionalidades e interatividade.

## 💻 Como executar o projeto

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Verifique se os arquivos estão organizados corretamente.
4. Abra o arquivo `index.html` no navegador.
5. Navegue pelo site e teste suas funcionalidades.

## 📱 Responsividade

O site foi desenvolvido para funcionar em diferentes tamanhos de tela, como:

- Computadores.
- Notebooks.
- Tablets.
- Celulares.

Este projeto foi desenvolvido com o objetivo de colocar em prática os conhecimentos adquiridos em HTML, CSS e JavaScript, criando um site funcional, organizado e de fácil utilização.
