# 🍕 Pizzaria Forno de Ouro

## 📌 Sobre o projeto

O **Pizzaria Forno de Ouro** é um projeto de desenvolvimento web criado com o objetivo de praticar conhecimentos em HTML, CSS e JavaScript. O site apresenta um cardápio de pizzas, promoções e um formulário para realizar pedidos.

## 🎯 Objetivos

- Desenvolver uma página web organizada e responsiva.
- Aplicar conceitos de HTML semântico.
- Organizar os estilos utilizando arquivos CSS separados.
- Utilizar JavaScript para validar e calcular pedidos.
- Melhorar os conhecimentos em desenvolvimento front-end.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da página.
- **CSS3:** estilização, layout e responsividade.
- **JavaScript:** validações, interações e cálculos dos pedidos.


## ✨ Funcionalidades

- Exibição do cardápio de pizzas.
- Apresentação de promoções.
- Menu de navegação.
- Formulário para pedidos.
- Validação dos dados preenchidos.
- Cálculo do valor total do pedido.
- Resumo do pedido na própria página.
- Layout adaptado para celulares e computadores.

## 🚀 Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Confira se os arquivos HTML, CSS e JavaScript estão nas pastas corretas.
4. Abra o arquivo `index.html` no navegador.

## 📚 Aprendizados

Este projeto permite praticar a estruturação de páginas web, a separação de responsabilidades entre HTML e CSS, o uso de variáveis, condicionais, laços de repetição, validações e manipulação de elementos da página com JavaScript.

## 👩‍💻 Autoria

Projeto acadêmico desenvolvido para fins de aprendizado e prática em desenvolvimento web.
